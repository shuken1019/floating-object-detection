# floating-object-detection

# 수중 부유물 탐지 및 분류 프로젝트 (Floating Object Detection)

수질 관리 및 환경 모니터링 효율화를 위해 YOLOv8 알고리즘을 활용하여 수면 위의 부유물(쓰레기 및 자연물)을 실시간으로 탐지하고 분류하는 프로젝트입니다.

## 📌 프로젝트 개요

- **목적**: 하천 및 바다 환경에서 플라스틱, 비닐 등 수질 오염원을 자동으로 식별
- **핵심 기능**: 부유물 객체 탐지
- **개발 환경**: Python, YOLOv8, Roboflow

## 🛠 기술적 특징

- **학습 모델**: YOLOv8 (Pre-trained model 활용)
- **데이터셋**: 직접 수집 및 라벨링한 1,988장의 이미지 데이터셋 구축
- **데이터 증강 (Augmentation)**:
  - Rotation, Hue, Brightness, Exposure, Blur 기법을 적용하여 모델의 성능 향상
- **탐지 클래스 (5종)**:
  - Plastic, Twig(나뭇가지), leaf(나뭇잎)

## 📈 추후 성능 개선 및 확장

- **환경 적응성**: 야간(Night) 및 우천(Rainy) 상황의 데이터를 학습에 포함하여 악조건에서도 높은 탐지 정확도 유지
- **멀티 클래스 확장**: 초기 3개 클래스에서 시작하여 5개 이상의 오염원 카테고리로 분류 체계 확장
